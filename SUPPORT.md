# Getting Support for x402-avm

Welcome to the x402-avm community. We provide multiple channels to help developers build, integrate, and deploy pay-per-call services on Algorand.

---

## 1. Documentation

Before seeking direct support, please consult the official documentation:

- **Documentation Portal**: [https://x402-avm.github.io](https://x402-avm.github.io)
  - **Getting Started**: Quickstarts, concepts, networks, and glossary.
  - **ai-economy-sdk Guides**: FastMCP server integration, client sessions, dynamic pricing, vendor passes, caller identity, and settlement.
  - **x402-algorand Guides**: AVM exact scheme mechanics, FastAPI/Flask middleware, and custom networks.
  - **x402-avm-js Guides**: Browser wallets (Pera, Defly, Lute), Node.js integration, and identity proofs.
  - **Tutorials**: Step-by-step walkthroughs for paid MCP tools, browser paywalls, and USDC on MainNet.

---

## 2. Code Examples

For working code snippets and reproducible patterns, refer to the examples repository:

- **Examples Repository**: [x402-avm/examples](https://github.com/x402-avm/examples)
  - Runnable scripts for Python and TypeScript.
  - Covered environments: LocalNet (funded via KMD dispenser), TestNet, and MainNet.

---

## 3. GitHub Discussions

For general architectural questions, implementation advice, or idea brainstorming:

- Visit the [x402-avm Discussions](https://github.com/orgs/x402-avm/discussions).
- Search existing threads to see if your question has already been answered.
- If creating a new discussion, choose the most appropriate category:
  - **Q&A**: Specific technical questions about integrating SDKs.
  - **Show and Tell**: Showcase projects, tools, or MCP servers you have built.
  - **Ideas**: Proposals for new features, wallet adapters, or protocol enhancements.

---

## 4. Reporting Bugs and Requesting Features

If you encounter a reproducible bug or wish to suggest a feature:

1. Search open and closed issues on the corresponding repository to avoid duplicates.
2. Open a new issue using our structured issue forms:
   - [`ai-economy-sdk` Issues](https://github.com/x402-avm/ai-economy-sdk/issues)
   - [`x402-algorand` Issues](https://github.com/x402-avm/x402-algorand/issues)
   - [`x402-avm-js` Issues](https://github.com/x402-avm/x402-avm-js/issues)
   - [`examples` Issues](https://github.com/x402-avm/examples/issues)
   - [`marketplace-demo` Issues](https://github.com/x402-avm/marketplace-demo/issues)
3. Fill out all requested form fields, including minimal reproducible code and environment details.

---

## 5. Security Vulnerabilities

If you suspect you have identified a security vulnerability, please do **not** report it via public issues or discussions.

Refer to our [Security Policy](SECURITY.md) to report the vulnerability privately via GitHub Private Vulnerability Reporting on the affected repository (`https://github.com/x402-avm/<repo>/security/advisories/new`).
